# Claude Meter v1.13.2

With **Always on top** off, the popup now behaves like a normal window.

## Update

On v1.13.0 or later, use **App → Check for updates now → Update now**. The app installs the update and restarts in a few seconds.

On an older version, download **`ClaudeMeter-portable.zip`** (attached), unzip it over your old folder, and run `ClaudeMeter.exe`.
No .NET installation is needed. If SmartScreen warns on first run, choose **More info → Run anyway**.

## Changed

- **The popup no longer disappears when you click another app.** With *Always on top* off, it stays open and other windows can simply cover it.
- **You can drag it anywhere**, with *Always on top* on or off, and it remembers where you put it.
- **Clicking the tray icon (or pressing the hotkey) brings a covered popup back to the front.** Press again to hide it. The **−** button and **Esc** still hide it as before.
- **Turning *Always on top* off no longer closes the popup.** It stays where it is and stops floating above other windows.
- A plain click on the popup no longer counts as a move, and a saved position is kept on-screen if the popup has grown since.

Your settings, saved usage history and login tokens are untouched.
