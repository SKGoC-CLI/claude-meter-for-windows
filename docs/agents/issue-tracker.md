# Issue tracker

Local markdown (chosen 2026-11-08 — the GitHub repo is public, so specs/tickets stay on disk).

- Specs and tickets live under `.scratch/<feature-slug>/`
  - `spec.md` — the spec
  - `NN-<slug>.md` — one file per ticket, with a `Blocked by:` line
- Triage label = a `Labels:` line at the top of the file (`ready-for-agent`, `needs-triage`, `done`).
