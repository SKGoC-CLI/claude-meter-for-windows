# Claude Meter v1.14.1

The popup now shows which version you're running, and tells you when there's a newer one.

## Update

On v1.13.0 or later, use **App → Check for updates now → Update now**. The app installs the update and restarts in a few seconds.

On an older version, download **`ClaudeMeter-portable.zip`** (attached), unzip it over your old folder, and run `ClaudeMeter.exe`.
No .NET installation is needed. If SmartScreen warns on first run, choose **More info → Run anyway**.

## Added

- **Version number in the header**: `Claude Usage Meter  v1.14.1`, in small muted text. It stays visible with the logo turned off.
- **Update hint**: when GitHub has a newer release, the label turns amber (`v1.14.1 → v1.14.2`). Click it to open the usual update prompt (Update now / What's new / Later). Clicking the label doesn't drag the popup.

Your settings, saved usage history and login tokens are untouched.
