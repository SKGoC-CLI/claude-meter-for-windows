## สิ่งที่เรียนรู้ — อย่าทดลองซ้ำ

1. **ตัวปัญหาคือสี accent ไม่ใช่พื้นหลัง** — B เปลี่ยนแค่พื้นเป็นครีมอุ่นโดยคงน้ำเงินไว้
   ผลคือ *แย่ลง* น้ำเงินเย็นบนครีมอุ่นขัดกันหนักกว่าน้ำเงินบนเทาเย็น
2. **โคลอลเป็นสี "ปกติ" ใช้ไม่ได้** (C) — 42% ส้มแดง กับ 93% แดง แยกกันไม่ออกในแถบเทียบ
   และสถานะปกติไม่ควรเป็นสีร้อนตั้งแต่แรก ความหมายเพี้ยน
3. **ให้กราฟใช้พาเลตต์เดียวกับ severity ทำให้กราฟตาย** (D) — พอ "ปกติ" เป็นหมึก
   กราฟก็กลายเป็นเทาซีดทั้งแผง
4. **กราฟกับ severity เป็นคนละหน้าที่** (E) — กราฟคือชุดข้อมูล ไม่ใช่สัญญาณความรุนแรง
   แยกสีได้โดยไม่ขัดหลัก เป็นทางที่ดีที่สุดในห้าแบบ แต่ยังไม่ถูกใจอยู่ดี

## ถ้าจะทำ E จริง

เพิ่ม `Theme.Graph` แล้วชี้โค้ดวาดกราฟมาที่ตัวนี้แทน `Theme.Accent` — 8 จุดใน
`src/PopupForm.cs` ราวบรรทัด 1031–1276 (`DrawRemainingChart` + `DrawCreditGraph`)
**`ContextColor` บรรทัด 157 ต้องคง `Accent` ไว้** เพราะมันเป็นตัวบอกความรุนแรงจริง

ข้อควรระวังที่ยังไม่ได้พิสูจน์: E ทำให้สีบน tray icon (ฟ้า/ส้ม/แดง) ไม่ตรงกับป๊อปอัปแล้ว
— ไอคอนสื่อ "ฟ้า = ปกติ" แต่ป๊อปอัปสื่อ "ดำ = ปกติ"

## ทางที่ยังไม่ได้ลอง

- เขียว/teal เป็นสถานะปกติ (ปกติ = เขียว เป็นภาษาที่คนอ่านออกทันที แต่ชนกับ
  reset marker สีเขียวในกราฟ ต้องเปลี่ยน marker ด้วย)
- ไล่เฉดสีเดียว (monochrome ramp) — อ่อน→เข้ม ในสีเดียวตามความรุนแรง
- ไม่มีสีในแถบเลย ใช้ความหนา/ลวดลายของแถบบอกความรุนแรงแทน
- ปรับ **dark theme** ให้อุ่นขึ้นตาม แล้วให้สองธีมเป็นครอบครัวเดียวกัน
  (รอบนี้ล็อก dark ไว้ไม่ให้ขยับเลย)
